1. 개인정보 처리의 목적

모리의 여행플랜(이하 '서비스')는 사용자의 여행 계획 관리 서비스를 제공하기 위해 개인정보를 처리합니다. 본 방침은 이용자의 개인정보 보호를 위해 작성되었으며, 서비스 이용 중 발생할 수 있는 개인정보 처리에 대하여 설명합니다.

본 개인정보처리방침은 웹(PWA) 버전과 Android 앱(모리의 여행플랜) 버전에 적용되며, 향후 출시되는 다른 플랫폼(iOS 등) 버전에도 동일하게 적용됩니다.

2. 수집하는 개인정보

2-1. Google Drive 연동 (선택)

서비스는 회원가입이나 로그인을 요구하지 않습니다. 사용자가 'Google Drive 백업·복구' 기능을 직접 사용할 때만 Google 계정 연결이 이루어지며, 이때 요청하는 권한은 '이 앱이 만든 파일에 한정된 Drive 접근 권한(drive.file)' 하나뿐입니다. 서비스는 이름, 이메일 주소, 프로필 사진을 가져오지 않습니다.

보안 참고: OAuth 토큰은 현재 탭의 메모리에만 있으며, 탭을 닫거나 페이지를 새로고침하면 사라집니다. 브라우저를 종료한 뒤 Drive 기능을 다시 쓰려면 Google 계정 연결을 다시 해야 합니다.

2-2. 로컬 저장 데이터

사용자의 브라우저 로컬스토리지에 저장되는 데이터:

데이터 항목 저장 위치 설명
여행 일정 로컬스토리지 여행 이름, 날짜, 여행 도시, 일정, 장소, 메모, 일차별 날씨 기록 등
지출 내역 로컬스토리지 금액, 통화, 분류, 결제수단
체크리스트 로컬스토리지 준비 항목, 완료 상태
설정 정보 로컬스토리지 테마, 배경 효과(파티클) 설정 등
여행 기록 로컬스토리지 지난 여행 아카이브

2-3. 기술적 정보

  • 캐시와 쿠키: 서비스는 자체 쿠키를 설정하지 않습니다. 오프라인 사용과 속도를 위해 같은 도메인의 정적 파일(화면, 이미지 등)만 브라우저 캐시(서비스워커)에 저장하며 개인 데이터는 들어가지 않습니다. 아래 5-2의 외부 서비스가 자체적으로 쿠키 등을 사용할 수 있습니다.
  • 환경 정보: 화면 크기와 기기 종류는 화면 구성을 맞추는 데에만 기기 안에서 쓰입니다. 이용 통계 도구(Google Analytics)가 브라우저와 기기 정보를 수집할 수 있습니다.

입력 데이터의 외부 제공 범위

사용자의 여행 데이터는 전적으로 개별 사용자의 로컬스토리지 또는 개별 Google Drive에만 저장됩니다. 서비스는 다음과 같이 운영합니다:

  • 여행 일정, 지출, 체크리스트 등 사용자가 입력한 데이터를 서비스 운영자의 서버에 저장하지 않음
  • 입력 데이터를 광고나 마케팅 업체에 넘기지 않음(사용자가 직접 누른 제휴·지도 링크의 주소에 도시명이나 장소명이 포함되는 경우와, 아래 5-2의 표에 적힌 항목은 예외입니다)
  • 법적 요청이 없는 한 정부기관에 제공하지 않음

4. 개인정보의 보관 기간

4-1. 로컬스토리지 데이터

  • 보관 기간: 사용자가 브라우저 데이터를 삭제할 때까지
  • 자동 삭제: 없음 (여행 기록은 사용자가 기록 화면에서 직접 삭제하거나 브라우저 저장 데이터를 지울 때 삭제됩니다. '여행 마무리'는 현재 여행을 여행 기록으로 옮겨 보관합니다.)

4-2. Google Drive 백업

  • 보관 기간: Google Drive 계정이 유지되는 동안
  • 삭제 방법: Google Drive에서 수동 삭제 또는 Google 계정 삭제

4-3. OAuth 토큰

  • 보관 기간: 브라우저 탭이 열려 있는 동안만(새로고침해도 사라집니다)
  • 자동 소실: 탭을 닫거나 새로고침하면 즉시 소실
주의: 서비스 이용 중단 시 저장된 데이터는 자동 삭제되지 않습니다. 필요시 사용자가 수동으로 삭제해야 합니다.

다만 아래 5-2의 서비스를 이용하면 그 서비스로 일부 정보가 전달됩니다.

5-2. 외부 서비스 이용 현황

서비스 목적 연결되는 때 전달될 수 있는 정보
Google Analytics 이용 통계 서비스 화면을 열 때 자동 방문한 화면, 기기와 브라우저 종류, 대략적인 지역, 쿠키 등 임의의 식별자(Google Analytics가 표준으로 수집하는 항목). 여행 일정과 지출 내용은 전달되지 않습니다.

Ko-fi 후원 후원 아이콘을 누를 때 접속 정보. 결제는 Ko-fi와 결제 대행사가 처리하며 서비스는 결제 정보를 받지 않습니다.

지도와 날씨 링크(Google 지도, 네이버 지도, 기상청, Weather.com) 장소와 날씨 확인 사용자가 링크를 누를 때 장소명이 주소에 포함될 수 있음
GitHub Pages 웹 호스팅 접속할 때 접속 정보(IP 등)

이들 서비스는 각각의 개인정보보호방침을 따릅니다:

  • GitHub 개인정보보호방침

향후 광고(Google AdSense 또는 AdMob)를 시작하면 쿠키와 맞춤 광고 선택 방법 등 광고 관련 안내를 이 방침에 추가합니다.

6. 개인정보 보호 조치

6-1. 기술적 보호 조치

  • HTTPS 암호화: 모든 통신은 SSL/TLS 암호화됨
  • 로컬스토리지 격리: 브라우저의 동일 출처 정책(Same-Origin Policy)으로 보호
  • Google Drive 보안: Google이 제공하는 보안과 접근 제어
  • 서비스워커 캐시: 오프라인 기능 제공 및 성능 최적화

6-2. 접근 제어

  • Drive 기능은 사용자가 직접 허용한 Google 계정 권한(이 앱이 만든 파일에 한정)으로만 접근합니다.
  • 로컬스토리지는 현재 도메인(moritravelplan.com)에서만 접근할 수 있습니다. 기기를 다른 사람이 쓸 수 있다면 기기의 잠금 설정으로 보호해 주세요.
  • Drive 접근 토큰은 메모리에만 있으며 저장되지 않습니다.

6-3. 주의 사항

사용자는 다음 사항을 반드시 지켜주세요:

  • 공용 컴퓨터에서는 사용 후 탭을 닫고 브라우저 저장 데이터를 삭제해 주세요
  • Google 계정의 보안을 유지 (강력한 비밀번호, 2단계 인증)
  • 피싱 이메일 및 의심스러운 링크를 피하기

  2. Google Drive 백업: Google Drive에서 백업 파일을 직접 삭제하고, Google 계정 설정의 '서드 파티 앱 및 서비스'에서 이 앱의 접근 권한을 삭제하세요.

삭제되는 데이터와 보관 기간

  • 여행 일정, 지출, 체크리스트, 날씨 기록, 여행 기록 등 직접 입력한 데이터는 기기(와 사용자가 만든 Google Drive 백업)에만 있고 서비스 운영자의 서버에는 저장되지 않습니다. 운영자가 보관하는 사용자 데이터가 없으며, 위 방법으로 삭제하면 바로 사라집니다.
  • 이용 통계(Google Analytics)는 개인을 직접 식별하지 않는 형태로 집계되며 보관 기간은 Google Analytics의 설정을 따릅니다.

7-1. 개인정보 열람 및 수정 요청

사용자는 다음의 권리를 행사할 수 있습니다:

  • 열람: 로컬스토리지 및 Google Drive에 저장된 자신의 데이터 확인
  • 수정: 서비스 내 편집 기능으로 데이터 직접 수정
  • 삭제: 진행 중인 여행을 '여행 마무리'하면 여행 기록으로 옮겨져 기기에 계속 보관됩니다. 여행 기록은 기록 화면에서 직접 삭제할 수 있고, 브라우저 저장 데이터를 지우면 기기의 모든 데이터가 삭제됩니다.
  • Google Drive 삭제: Google Drive에서 직접 백업 파일 삭제 가능

7-2. 데이터 이동권

  • JSON 형식으로 데이터 내보내기 기능 제공
  • 엑셀(CSV) 형식으로 데이터 다운로드 가능
  • 다른 서비스로의 데이터 이전 용이

7-3. 동의 철회

  • Google Drive 연동: Drive 기능은 사용자가 직접 사용할 때만 연결됩니다. 연결을 끊고 싶다면 Google 계정 설정의 '서드 파티 앱 및 서비스' 메뉴에서 이 앱의 접근 권한을 삭제할 수 있습니다. 백업 파일은 본인의 Google Drive에서 직접 삭제할 수 있습니다.
  • 서비스 이용 중단: 서비스에는 계정이 없습니다. 앱 안의 기록 화면에서 여행 기록을 직접 삭제하거나, Chrome(브라우저)의 사이트 설정에서 moritravelplan.com 데이터를 삭제하면 기기의 데이터가 삭제됩니다.
